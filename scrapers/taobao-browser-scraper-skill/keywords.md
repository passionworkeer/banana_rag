## 通用品牌关键词

通用关键词"蕉内"每页返回约 48 个商品，覆盖所有品类，但在第 5-6 页后趋于饱和，重复度很高。

## 适配其他品牌

将"蕉内"替换为目标品牌名，按同样方式生成品类关键词：

```python
brand = "优衣库"
categories = ["T恤", "裤子", "外套", "内衣", "袜子", ...]
keywords = [f"{brand}{cat}" for cat in categories]
```

## URL 编码参考

常见中文字符的 URL 编码：
- 蕉内 = %E8%95%89%E5%86%85
- T恤 = T%E6%81%A4
- 卫衣 = %E5%8D%AB%E8%A1%A3
- 外套 = %E5%A4%96%E5%A5%97
- 内裤 = %E5%86%85%E8%A3%A4

Python 中使用 `urllib.parse.quote(keyword)` 进行编码。
