# 前端 AI 应用与产品设计面试题库

## 核心论点

本文件是面试前端 AI 应用与产品设计题目的 Markdown 题库,覆盖 AI Agent 工作流可视化编辑器选型(画布层 React Flow/X6 + 节点配置层 LLM/Tool/Condition/Human + 执行引擎层 + 调试观测层,核心是 DSL 可执行 + 调试可回放)、前端 AI 质量监控(首 token 延迟、完整响应耗时、中断率、重试率、工具调用失败率、用户采纳率、负反馈率、错误边界触发次数,分体验/质量/稳定性三层)、多模态消息协议(把文本/图片/语音/视频统一成 message + type/metadata/upload status/preview/processing state,大文件先上传拿 file id,前后端职责解耦)、WebLLM 端侧模型(价值是低延迟 + 隐私 + 离线 + 降云端成本,适合轻量摘要/分类/隐私预处理,不适合超大推理/企业核心/低端设备)、AI 幻觉 UI 反馈(展示引用来源 + 标注"需确认" + 一键纠错 + 高风险二次确认 + 推理依据可视化)、MiniMax Agent 优化(任务完成率、工具生态、记忆、可控性、垂直场景;优化重点是稳定 + 可解释 + 可信)。

核心方法论是"前后端职责分离 + 显式不确定性":Agent 工作流编辑器不是只做拖拽画布,而是设计可执行 DSL 和调试链路;前端 AI 质量监控要分体验(延迟/中断) + 质量(采纳/反馈) + 稳定性(工具调用/WebSocket/上传)三层;多模态前端要把所有模态抽象成统一 message 协议,不直接耦合模型处理细节;AI 幻觉在 UI 层要显式设计不确定性反馈,不是只在底部放"AI 可能出错"。
