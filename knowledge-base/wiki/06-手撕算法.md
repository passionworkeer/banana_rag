# 手撕算法面试题库

## 核心论点

本文件是面试手撕算法题目的 Markdown 题库,覆盖 NumPy 手写 Multi-Head Attention(Q/K/V 投影 + 分头 + 缩放点积 + mask + softmax + 拼接 + 输出投影)、PyTorch 手写 SFT Loss(对 label 做 shift、padding 用 -100 mask)、快排(选 pivot + 左右分区 + 递归)、第 K 大元素(快速选择 partition)、最大正方形(DP)、接雨水(双指针或单调栈)、最长递增子序列(LIS,O(N log N) 耐心排序)、三数之和(排序 + 双指针)、盛最多水(双指针)、并发队列调度系统(可配置并发数 + 优先级调度 + TCP 拥塞控制类比)。

核心方法论是"先把骨架写对再优化":Multi-Head Attention 手撕重点是 Q = X @ Wq、K = X @ Wk、V = X @ Wv 三个投影、split_heads 转成 [B, H, L, Hd]、scores / sqrt(head_dim) 缩放、mask 用 -1e9 屏蔽、softmax 后乘 V、combine_heads 转回 [B, L, D]、最后 @ Wo 投影;SFT Loss 关键是 logits[:, :-1] 对齐 labels[:, 1:]、ignore_index=-100 mask padding;快排三段式(左小 / 等于 / 右大);第 K 大用 partition 把 target = len(nums) - k 当作定位点;DP 题先定状态再推转移。面试答题策略是"先写骨架 + 口头说明时间和空间复杂度 + 主动指出边界 case"。
