# 工程基础面试题库

## 核心论点

本文件是面试工程基础题目的 Markdown 题库,覆盖 Go 协程/GMP 调度(G 比线程更轻、M 是 OS 线程、P 是执行上下文、work stealing 提高调度)、goroutine 泄露(channel 无人接收、select 无退出、context 忽略)、Go 内存模型(mcache/mspan/mheap 分级)、MySQL 事务 ACID + MVCC(每行带版本、Read View、快照读提高并发)、B+ 树索引与覆盖索引(避免回表)、SQL 时间复杂度(主键 O(logN)、全表 O(N)、范围看区间)、Redis 数据结构 + pipeline/Lua 原子执行、Redis 中心 vs 共享缓存、一致性与热点策略、MQ 延迟与低优先级(分 topic / 分消费者组 / 消费端优先级调度)、WebSocket vs HTTP/SSE、文件上传与分片、断点续传、令牌桶算法与优先级调度、vLLM/SGLang 推理框架、服务治理(熔断/限流/降级)、线上故障排查(依赖、NoClassDefFound、流量峰值)。

核心方法论是"分层选型 + 抓瓶颈":Go 分级分配是为了让小对象在本地快速分配,减少全局锁竞争;MySQL 单点主键查询接近 O(logN) 但要确认是否命中索引,索引覆盖减少回表成本;Redis pipeline/Lua 解决高并发限流和扣库存的原子性;vLLM 通过 PagedAttention 优化 KV Cache 显存管理,SGLang 通过 RadixAttention 基于前缀树复用 KV;线上故障排查要先看监控、依赖、容量,再定位到代码层。
