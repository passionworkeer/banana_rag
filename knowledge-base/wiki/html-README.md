# 面试与学习中心 · 浏览指南

## 核心论点

`interview/html/` 是全本地、不联网的面试与学习中心,入口为 `index.html`。整体定位是一张张"图 + 文字 + 公式"组合的纯本地 HTML 知识页,统一格式为 hero + 架构图 SVG + 公式/表格 + 8-10 条 FAQ + 回答模板 + 概念速查表,配色按方向区分:紫 #7c3aed(对齐训练 / Agent)、蓝 #2563eb(推理部署)、天蓝 #0ea5e9(AI PM)。首次浏览建议按 index 顺序 30 分钟扫一遍,每张页 5 分钟细看,面试前一晚集中过"回答模板 + 概念速查表"。

指南提供了四条定向精读路径,对应四类岗位:Agent 岗(agent → a2a → multi-agent → mcp → tool-use → agent-observability → browser-agent → context-engineering → prompt-injection)、推理部署岗(transformer → kv-cache → flash-attention → paged-attention → speculative-decoding → quantization → inference-engines → long-context)、训练/推理研究员(sft → lora → rlhf → ppo → grpo → dpo-advanced → reward-model → constitutional-ai → reasoning-models)、AI PM(ai-pm → context-engineering → prompt-engineering → prompt-injection → agent-observability → router → planner)。2025 年新增三大方向是 Reasoning(o1/R1/Test-Time Compute/PRM)、多模态(VLM + document-parsing)、Agent 落地(browser-agent + agent-observability)。门面 3 张是 reasoning-models、a2a、flash-attention。
