# 答题规范与公式速查

## 核心论点

本文件不是单独的题库,而是"答题骨架 + 公式卡片 + HTML 展示模板"的可复用基础设施,适用于所有面试题的解答。通用答题结构是五段式:一句话结论 → 核心原理 → 知识点展开(补公式、定义、边界和对比) → 工程落地(项目里怎么用) → 常见追问(提前补面试官会继续问的点)。这套骨架的价值是把表达流程模板化,让答题不再依赖临场发挥,而是按既定顺序填充。

公式卡覆盖了面试最常考的 9 个公式:Attention(Q = XWq, K = XWk, V = XWv; Attention = softmax(QK^T / sqrt(d_k))V)、Cross-Entropy(L = -∑y_i log p_i)、Softmax、cosine similarity、欧氏距离、F1(2PR / (P+R))、KL 散度、LoRA(W' = W + BA)、DPO 直观形式。HTML 展示模板支持 `<details>` 折叠卡和 `<div>` 重点提示两种用法,直接嵌入 Markdown。表达模板按题型分为讲技术题、讲项目题、讲优化题、讲评估题四类,各有可套用的固定句式。建议阅读顺序从 01-大模型基础 开始,逐步覆盖 8 个主题方向。
