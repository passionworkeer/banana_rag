# 面试题库索引

## 核心论点


Markdown 题库八大类分工:**01-大模型基础** (Transformer/Attention/KV Cache/MoE/长上下文)、**02-Agent与RAG** (RAG 评估/切片/Rerank/Agent 框架/多 Agent)、**03-模型训练与对齐** (SFT/LoRA/PPO/DPO/GRPO/KL/Reward)、**04-多模态与文档解析** (OCR/MinerU/图文对齐/视觉检索)、**05-工程基础** (Go/MySQL/Redis/MQ/WebSocket/vLLM)、**06-手撕算法** (Multi-Head/SFT Loss/快排/K 大/正方形/接雨水/LIS/三数之和)、**07-项目深挖与行为题** (实习/项目/RL 训练/Agent 业务)、**08-前端AI应用与产品设计** (工作流编辑器/质量监控/WebLLM/幻觉)。**00-答题规范与公式速查**是通用答题骨架。

整理规则:相同题不重复写(用"相似问法"标注);每题给可面试回答(结构化答案);技术题按层次(结论/原理/落地/追问);项目题按四段(业务/拆解/动作/验证);不确定事实不伪造(用"阶段性指标/可以这样设计"表达)。**新 HTML 知识页**直接放到 `html/`,命名按主题,首页 index.html 自动收录。
