# 模型训练与对齐面试题库

## 核心论点

本文件是面试模型训练与对齐题目的 Markdown 题库,覆盖 SFT 流程与数据集构建、SFT loss 与 shift right 原因、LoRA 原理(冻结 W + 低秩 A·B、公式 W' = W + BA、r 选择小值起步消融、推理时可 merge)、全量微调与 LoRA 显存差异(全量含参数 + 梯度 + optimizer state + activation,LoRA 主要省梯度和优化器状态)、PPO vs DPO(PPO 是在线 RL + Reward Model + 价值函数,DPO 是把偏好优化转成监督式目标不再做 rollout)、KL 散度作用(约束新策略不偏离参考模型太远)、Reward Model 设计、RLHF 业务场景、GRPO 选型、Reference Model 缺失后果、训练中学歪了处理(奖励黑客/格式奖励/正则化/多 reward 加权)、强化学习训练指标(平均 reward/KL 散度/胜率/策略比例)、DPO 训练参数(beta、学习率、batch size、reference model 冻结)等。

核心方法论是"目标、约束、代价"三视角:SFT 解决"按指令输出",关键在数据多样性和质量(覆盖不同问题类型、答案标准一致、避免模板化、保留任务真实分布);PPO/DPO 解决"按偏好输出",DPO 省掉 rollout 和 value 更新但对偏好数据质量更敏感;RL 训练必须用 KL 约束防止语言能力退化;LoRA 通过冻结主干权重把训练显存大幅降下来,适合资源有限或多任务快速适配。实验流程的常见观察是"数据去重/清洗/难例补充带来的收益往往比盲目调模型结构更大"。
