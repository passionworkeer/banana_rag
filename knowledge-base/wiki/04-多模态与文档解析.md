# 多模态与文档解析面试题库

## 核心论点

本文件是面试多模态与文档解析题目的 Markdown 题库,覆盖 OCR 原理(检测 + 切分 + 识别 + 后处理)、OCR 局限(图文混排、复杂表格、模糊图、手写、图纸)、OCR → 多模态的转型收益场景(图纸版面依赖空间布局、公式/表格/标注箭头、图片无完整文字描述)、图文模态对齐方案(双塔对比学习、Cross-Attention 融合、跨模态编码器、检索时统一 embedding)、图纸类无文本对应描述的视觉特征召回(图像编码器抽特征、文本 query 编码、统一 embedding 空间、视觉 rerank)、MinerU 复杂工业文档解析流程(页面检测 + 版面分析 + 分区 + 跨页表格合并 + 结构化输出)、复杂图文混排难点(文本顺序与视觉布局不一致、表格跨页、脚注/图注/箭头、跨栏)、专业术语语义偏移(术语词典、query rewrite、领域 embedding 微调、rerank 训练、文档规范化)、Ragas 在多模态评估中的延伸等。

核心方法论是"恢复结构 + 统一空间":复杂工业文档解析的关键不是"识别出字"而是"恢复结构",要先做版面分析再按章节/段落/表格切分;多模态检索要先让图片和文本进入统一向量空间,再在统一空间做相似度召回;纯 OCR 方案在结构敏感场景(图纸、公式、复杂版面)会丢失空间关系和视觉结构,必须升级到多模态;对专业术语的语义偏移,要建立术语词典 + 领域 embedding 微调 + 文档规范化的组合方案。
