# 项目深挖与行为题面试题库

## 核心论点

本文件是面试项目深挖与行为题题目的 Markdown 题库,覆盖长期实习意愿表达(明确问题定义 + 持续迭代空间 + 方法论沉淀 + 真实反馈)、最熟 Agent/RAG 项目讲述四段(业务背景、用户需求、我的角色、方案搭建、效果验证)、数据处理难点(去重/标准化/抽检/难例沉淀)、数学解题业务本质(识别 + 理解 + 步骤 + 标准答案 + 多模态)、OCR → 多模态转型原因(快速验证 → 结构敏感)、多模态收益场景(图纸/表格/截图/标注)、训练流程最大收益块(数据处理 + 训练目标一起,去重/清洗/难例补充 + 格式统一比调结构收益大)、模糊图鲁棒性(低质量输入下从视觉特征 + 上下文 + 局部结构恢复语义)、去重的量化收益(命中率/收敛稳定性/重复错误/人工修正)、RL 负责哪一块(数据/奖励/训练/评估四选一,不要泛泛说"都做了")、Reward 定义与不合理处理(稀疏奖励 + 奖励黑客 + 人工抽检)、学歪处理(回滚 + 调 reward + KL 约束)、GRPO 选型原因(对比 PPO/DPO、效率与稳定性)、小模型 80%+ 效果核心(数据质量 + 训练目标 + 推理优化)、Agent 推荐与传统推荐区别(对话 + 工具 + 决策 vs 静态排序)、Multi-Agent 最关键部分(任务路由 + 共享状态 + 冲突解决)、Memory 实际收益(长对话一致 + 偏好沉淀 + 跨会话召回)、OpenClaw 看法(任务模板 + 工具生态 + 记忆 + 可控性)、发券运营自动化设计(任务拆解 + 风险断点 + 人工确认)、Agent 业务最大风险(决策不可解释 + 数据隐私 + 工具误调 + 用户信任)。

核心方法论是"按四段讲项目 + 按业务本质拆解":所有项目用"业务问题 - 我的拆解 - 我的动作 - 验证结果"四段式;训练类项目强调"数据处理 + 训练目标"组合贡献;Agent 类项目强调"任务路由 + 工具编排 + 评估闭环";行为题要"先结论再展开 + 先业务再技术 + 先指标再叙述 + 先边界再能力"。
