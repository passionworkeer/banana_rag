# 06 手撕算法

## 1. 手写 Multi-Head Attention（NumPy 版）

核心回答：

> 面试手撕时，重点不是写得多花，而是把 Q/K/V 投影、分头、缩放点积、mask、softmax、拼接和输出投影写清楚。

```python
import numpy as np

def softmax(x, axis=-1):
    x = x - np.max(x, axis=axis, keepdims=True)
    exp_x = np.exp(x)
    return exp_x / np.sum(exp_x, axis=axis, keepdims=True)

def split_heads(x, num_heads):
    # x: [B, L, D]
    B, L, D = x.shape
    head_dim = D // num_heads
    x = x.reshape(B, L, num_heads, head_dim)
    return np.transpose(x, (0, 2, 1, 3))  # [B, H, L, Hd]

def combine_heads(x):
    # x: [B, H, L, Hd]
    B, H, L, Hd = x.shape
    x = np.transpose(x, (0, 2, 1, 3))
    return x.reshape(B, L, H * Hd)

def multi_head_attention(x, Wq, Wk, Wv, Wo, num_heads, mask=None):
    # x: [B, L, D]
    Q = x @ Wq
    K = x @ Wk
    V = x @ Wv

    Q = split_heads(Q, num_heads)
    K = split_heads(K, num_heads)
    V = split_heads(V, num_heads)

    head_dim = Q.shape[-1]
    scores = (Q @ np.transpose(K, (0, 1, 3, 2))) / np.sqrt(head_dim)  # [B,H,L,L]

    if mask is not None:
        scores = np.where(mask, scores, -1e9)

    attn = softmax(scores, axis=-1)
    out = attn @ V  # [B,H,L,Hd]
    out = combine_heads(out)  # [B,L,D]
    return out @ Wo
```

## 2. 手写 SFT loss（PyTorch 版）

核心回答：

> 关键是对 label 做 shift，并对 padding 位置做 mask。

```python
import torch
import torch.nn.functional as F

def sft_loss(logits, input_ids, pad_id=-100):
    """
    logits: [B, L, V]
    input_ids: [B, L]
    """
    shift_logits = logits[:, :-1, :].contiguous()
    shift_labels = input_ids[:, 1:].contiguous()

    loss = F.cross_entropy(
        shift_logits.view(-1, shift_logits.size(-1)),
        shift_labels.view(-1),
        ignore_index=pad_id,
    )
    return loss
```

## 3. 手写快排

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    mid = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + mid + quick_sort(right)
```

## 4. 第 k 大元素

```python
import random

def find_kth_largest(nums, k):
    target = len(nums) - k

    def partition(l, r):
        pivot = nums[r]
        i = l
        for j in range(l, r):
            if nums[j] <= pivot:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        nums[i], nums[r] = nums[r], nums[i]
        return i

    l, r = 0, len(nums) - 1
    while l <= r:
        p = partition(l, r)
        if p == target:
            return nums[p]
        elif p < target:
            l = p + 1
        else:
            r = p - 1
```

## 5. 由 0/1 组成的矩阵，返回全 1 的最大正方形面积

```python
def maximal_square(matrix):
    if not matrix or not matrix[0]:
        return 0
    m, n = len(matrix), len(matrix[0])
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    ans = 0
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if matrix[i - 1][j - 1] == '1' or matrix[i - 1][j - 1] == 1:
                dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
                ans = max(ans, dp[i][j])
    return ans * ans
```

## 6. 盛最多水的容器

```python
def max_area(height):
    l, r = 0, len(height) - 1
    ans = 0
    while l < r:
        ans = max(ans, min(height[l], height[r]) * (r - l))
        if height[l] < height[r]:
            l += 1
        else:
            r -= 1
    return ans
```

## 7. 接雨水

```python
def trap(height):
    if not height:
        return 0
    l, r = 0, len(height) - 1
    left_max = right_max = 0
    ans = 0
    while l < r:
        if height[l] < height[r]:
            if height[l] >= left_max:
                left_max = height[l]
            else:
                ans += left_max - height[l]
            l += 1
        else:
            if height[r] >= right_max:
                right_max = height[r]
            else:
                ans += right_max - height[r]
            r -= 1
    return ans
```

## 8. 最长递增子序列

```python
from bisect import bisect_left

def length_of_lis(nums):
    tails = []
    for x in nums:
        i = bisect_left(tails, x)
        if i == len(tails):
            tails.append(x)
        else:
            tails[i] = x
    return len(tails)
```

## 9. 流式输入输出规则题怎么做？

核心回答：

> 这类题通常考规则解析和状态机。先定义输入扫描规则，再按字符流维护状态，比如是否在包裹内、是否在转义状态、是否需要隐藏某些字符。

思路：

- 用状态机维护当前是否处于特殊块。
- 对被包裹的内容按规则隐藏或忽略。
- 对需要输出的内容直接拼接。
- 注意边界条件和连续符号。

## 10. 为什么 SFT 里的 shift right 很关键？

核心回答：

> 因为自回归训练的目标是用前面的 token 预测后面的 token。shift right 之后，模型在位置 t 的输出对齐的是 t+1 的标签，保证训练目标和推理方式一致。

## 11. 手撕可配置并发的请求队列调度系统（Go 版）

核心回答：

> 重点是任务队列、worker pool、context 取消、并发数配置和结果返回。

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"time"
)

type Job struct {
	ID int
}

type Result struct {
	ID  int
	Err error
}

type Scheduler struct {
	concurrency int
	jobs        chan Job
	results     chan Result
}

func NewScheduler(concurrency int, queueSize int) *Scheduler {
	return &Scheduler{
		concurrency: concurrency,
		jobs:        make(chan Job, queueSize),
		results:     make(chan Result, queueSize),
	}
}

func (s *Scheduler) Submit(job Job) {
	s.jobs <- job
}

func (s *Scheduler) Results() <-chan Result {
	return s.results
}

func (s *Scheduler) Run(ctx context.Context) {
	var wg sync.WaitGroup
	for i := 0; i < s.concurrency; i++ {
		wg.Add(1)
		go func(workerID int) {
			defer wg.Done()
			for {
				select {
				case <-ctx.Done():
					return
				case job, ok := <-s.jobs:
					if !ok {
						return
					}
					err := handle(ctx, job)
					s.results <- Result{ID: job.ID, Err: err}
				}
			}
		}(i)
	}

	go func() {
		wg.Wait()
		close(s.results)
	}()
}

func handle(ctx context.Context, job Job) error {
	select {
	case <-ctx.Done():
		return ctx.Err()
	case <-time.After(100 * time.Millisecond):
		fmt.Println("done", job.ID)
		return nil
	}
}
```

## 12. 流式输入输出处理规则题：包裹字符隐藏，MCP 调用只输出 instruction

核心回答：

> 用状态机处理。遇到特殊开始标记进入隐藏状态，遇到结束标记退出；遇到 MCP 块时解析 instruction 字段，只输出 instruction。

伪代码：

```python
def filter_stream(tokens):

    out = []

        if token == "<hidden>":
            hidden = True
            continue
        if token == "</hidden>":
```

## 附录 A：手撕题复杂度与面试讲法

### A1. Multi-Head Attention 必讲点

复杂度：

```text
时间复杂度：O(B * H * L^2 * d_head)
空间复杂度：O(B * H * L^2)
```

其中：

- `B`：batch size。
- `H`：head 数。
- `L`：序列长度。
- `d_head`：单头维度。

面试讲法：

> 我先做 Q/K/V 投影，再 reshape 成多头形式。核心计算是 `QK^T / sqrt(d)`，再经过 softmax 得到注意力权重，最后乘 V 并把多头拼回去。

### A2. SFT Loss 必讲点

为什么要 `ignore_index`：

- padding 不应该参与 loss。
- tool response 或 system prompt 有时也不应参与 loss。
- 只训练 assistant 输出部分更符合对话模型训练。

常见追问：

> tool response 需要 loss mask 吗？

回答：

> 一般需要 mask。工具响应是外部系统返回的结果，不是模型应该学习生成的自然语言；否则模型可能学会伪造工具输出。

### A3. 快排为什么平均 `O(n log n)`，最坏 `O(n^2)`

平均情况：

- pivot 把数组分成比较均衡的两部分。
- 递归深度约 `log n`。
- 每层总扫描 `n`。

最坏情况：

- pivot 每次都是最大或最小。
- 递归深度变成 `n`。
- 总复杂度 `O(n^2)`。

优化：

- 随机 pivot。
- 三路快排处理重复元素。

### A4. 第 K 大元素为什么可以用 Quickselect

Quickselect 不需要完全排序，只需要把目标位置放对。

复杂度：

```text
平均 O(n)
最坏 O(n^2)
```

面试表达：

> 排序是把所有位置排对，但第 K 大只关心一个位置，所以可以用 partition 每次丢掉一半左右的搜索空间。

### A5. 最大正方形 DP 推导

状态：

```text
dp[i][j] = 以 (i,j) 为右下角的最大正方形边长
```

转移：

```text
if matrix[i][j] == 1:
  dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
else:
  dp[i][j] = 0
```

原因：

> 一个点能扩成更大的正方形，必须要求上、左、左上三个方向都能支撑。

### A6. 接雨水双指针为什么成立

核心逻辑：

- 某个位置能接多少水，取决于左右最大高度的较小值。
- 当 `left_max < right_max` 时，左边当前位置的水量已经确定。
- 反之处理右边。

公式：

```text
water[i] = min(max_left[i], max_right[i]) - height[i]
```

### A7. LIS 二分法为什么正确

`tails[i]` 表示长度为 `i+1` 的递增子序列中，最小可能结尾值。

为什么替换：

> 结尾越小，后续越容易接上更大的数，所以用更小的结尾替换不会让答案变差。

复杂度：

```text
O(n log n)
```

### A8. 并发队列调度题追问

可能追问：

- 怎么动态调整并发？
- 怎么保证高优先级？
- 怎么处理超时？
- 怎么避免任务丢失？

答法：

- 动态并发：根据 P95 延迟和错误率调 worker 数。
- 高优先级：优先级队列或多队列加权轮询。
- 超时：每个任务带 context。
- 不丢失：持久化队列或失败重试。
