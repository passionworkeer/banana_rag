VLM：让 LLM 看见世界的桥

Visual Language Model 把图像 / 视频编码为"视觉 token"，与文本 token 一起送入 LLM 主干。LLaVA / Qwen-VL / InternVL 是开源代表，GPT-4V / Claude 3.5 Sonnet / Gemini 1.5 Pro 是闭源旗舰。架构 3 段：Vision Encoder → Projector → LLM。本页讲清训练 3 阶段、模态对齐、典型评测、应用边界。

二、视觉编码器选型

  • CLIP ViT-L/14：LLaVA 默认，强语义对齐
  • SigLIP：Google 出，sigmoid loss 训得更稳，Qwen-VL 用
  • DINOv2：Meta 自监督，强几何 / 细节
  • InternViT：上海 AI Lab，专门为 VLM 设计
  • 分辨率：224-336（标准）/ 448 / 896 / 动态（高分辨率图表必备）
视觉编码器常"冻结"——避免破坏已学表征；Projector 才是"对齐"关键训练对象。

三、Projector 设计

  • 线性投影（Linear）：LLaVA-1.0 风格，单层线性
  • 2 层 MLP：LLaVA-1.5 默认，能力更强
  • Q-Former：BLIP-2 风格，perceiver 重采样压缩 token 数
  • Cross-Attention：Flamingo 风格，LLM 主干中插入 cross-attn 层
  • 动态分辨率：高分辨率图切多块，每块独立编码
Projector 决定"信息密度"——压缩比例太高丢信息，太低 LLM 处理成本高。

六、VLM 评测 4 类

  • VQA 基础：VQA v2、OK-VQA（常识）
  • OCR / 文档：DocVQA、ChartQA（图表理解）
  • 幻觉：POPE、HallusionBench（评估"胡说"率）

VLM 评测比纯文本难——同一图可能有多个"正确"描述，需要用 GPT-4V 当 judge。

七、面试 FAQ

Q1：VLM 三段架构各自作用？

A：Vision Encoder（CLIP / SigLIP）把图编为视觉特征；Projector（MLP / Q-Former）把视觉空间映射到 LLM 的 token 空间；LLM 主干（Causal LM）把视觉 token 和文本 token 一起处理生成回答。VLM 训练的核心是"让视觉 token 看起来像文本 token"。

Q2：VLM 训练为什么分 3 阶段？

A：① Stage 1 只训 Projector，成本低、避免破坏视觉 / 文本已学表征；② Stage 2 训 Projector + LLM，让模型学"看图回答"；③ Stage 3 RLHF/DPO 选做，对齐人类偏好。3 阶段渐进解耦，避免灾难性遗忘。

Q3：为什么 Vision Encoder 通常冻结？

A：CLIP / SigLIP 已经在大规模图文对上预训练，表征已很强。冻结可避免破坏 + 省显存。少数 SOTA VLM（InternVL）解冻 Vision Encoder 进一步提效果，但成本涨。

Q4：VLM 主要瓶颈是什么？

A：3 个：① 高分辨率图像 token 数爆炸（1024×1024 → 4096 token）；② OCR / 细节能力（图表、文档理解）；③ 幻觉（VLM 容易"看见不存在"的东西）。Qwen-VL / InternVL 在 ②③ 上领先。

Q5：VLM 和 LLM 相比新引入了什么风险？

A：① 视觉注入（图片里嵌入恶意文本 → 间接 prompt injection）；② 训练数据偏见放大（视觉偏见比文本更难去）；③ OCR 错误传播（识别错 → 推理全错）。安全上需要"图像内容审查"层。

Q6：动态分辨率 VLM 怎么工作？

A：把高分辨率图切多块（如 448×448 patch 切 4-16 块），每块独立编码成 token，再加一个"缩略图" token 保留全局信息。Qwen-VL / InternVL 都用此招处理图表 / 文档。代价是 token 数线性涨。

Q7：VLM 怎么和 Agent 集成？

A：3 个场景：① 截图理解（VLM 看浏览器 / App 截图，操作 UI）；② 文档理解（VLM 解析 PDF / 图表，回答问题）；③ 视频分析（VLM 处理视频帧序列）。Computer Use / Browser Agent 是热门方向。

Q8：开源 VLM 怎么选？

A：① 中文场景优先 Qwen-VL / InternVL；② 英文 OCR 强选 InternVL / CogVLM；③ 部署成本敏感选 LLaVA-1.5（轻量）；④ 通用能力最强闭源 GPT-4V / Claude 3.5 / Gemini 1.5 Pro。生产上多模型 ensemble 也是常见选择。

八、回答模板与加分项

30 秒电梯版

VLM = Vision Encoder + Projector + LLM 主干。视觉编码（CLIP / SigLIP）把图转特征，Projector（MLP / Q-Former）映射到 LLM token 空间，LLM 统一处理生成回答。3 阶段训练：模态对齐 / 指令微调 / RLHF-DPO。代表：LLaVA / Qwen-VL / InternVL / GPT-4V / Claude 3.5。

5 分钟深入版

从动机（LLM 看不见）→ 3 段架构 → 视觉编码器选型（CLIP / SigLIP / DINOv2）→ Projector 设计（MLP / Q-Former / Cross-Attn）→ 3 阶段训练（对齐 / 指令 / RLHF）→ 5 大开源 VLM 对比 → 4 类评测 → 与 Agent 集成（Computer Use / 文档解析）。能讲清"为什么分 3 阶段训练"、"为什么视觉 Encoder 通常冻结"、"高分辨率怎么解决"，立刻显得跟得上时代。

加分：项目案例

讲一次"从 OCR + LLM 切到 VLM"——比如原本文档解析是 PaddleOCR 抽文字 + LLM 总结，遇到图表就废；切 Qwen-VL 后图、表格、文字统一处理，文档 QA 准确率从 65% 升到 88%。

加分：知道局限

VLM 不是银弹：① 高分辨率 token 爆炸；② 幻觉比纯 LLM 严重；③ 训练成本高；④ 视觉注入是新攻击面。诚实说"VLM 适合图表 / 文档 / 截图，不适合纯文本场景"得分更高。
