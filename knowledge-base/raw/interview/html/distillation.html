Distillation：把大模型的能力"压"进小模型

模型蒸馏（Distillation）让小模型（Student）模仿大模型（Teacher）的输出分布，把 Teacher 的"暗知识（dark knowledge）"——不只是 hard label，还有概率分布、中间表征、推理过程——学到。Hinton 2015 经典 KD → BERT-Pkd → MiniLLM → DeepSeek R1-Distill → Self-Distillation。本页把"原理 → 5 大类方法 → 与 SFT 区别 → R1-Distill 实战 → 面试 FAQ"一次性串清楚。

一、为什么需要 Distillation

  • 部署成本：7B 模型在端侧 / 边缘可跑，70B 不行
  • 推理速度：小模型 latency 3-5x 低于大模型
  • 暗知识（Dark Knowledge）：Teacher 的 soft label 比 hard label 携带更多信息（哪些"近似错误"被压低）
  • 能力迁移：Reasoning、Code、Math 能力可从 671B 蒸馏到 1.5B-32B
  • 与量化互补：先蒸馏到小模型，再 INT4 量化，可保持 90%+ Teacher 能力
关键认知：蒸馏 ≠ SFT。SFT 学的是"输入 → 输出"的硬标签，蒸馏学的是"Teacher 的完整概率分布"。SFT 让模型"会答"，蒸馏让模型"会思考"。

二、经典 Logit KD（Hinton 2015）

核心公式

LKD = (1 − α) · LCE(zS, y) + α · T² · LKL(softmax(zS/T) ‖ softmax(zT/T))

其中：

zS, zT：Student / Teacher 的 logits

T：温度（>1 软化分布，揭示暗知识）

α：蒸馏损失权重（典型 0.5-0.9）

LCE：与 hard label 的交叉熵（保 SFT 能力）

LKL：KL 散度（与 Teacher 软分布对齐）

关键：温度 T 越高，分布越软、相对关系越清晰（如"猫 0.7 / 狗 0.2"比"猫 1.0"告诉 Student 更多相似度信息）。T=1 等价标准 softmax，T=20 是常见选择。乘 T² 是补偿软化后的梯度量级。

三、Distillation 整体流程

T = T-softmax(logits/T) （携带暗知识） Input x （同 teacher） Student Forward （可训练，更新参数） Soft Logits / Hidden zS = T-softmax(logits/T) （学生预测） KD Loss KL(zS/T ‖ zT/T) · T² + CE(zS, y)

五、LLM 专属蒸馏：MiniLLM / GKD / R1-Distill

MiniLLM（2022, Gu et al.）

用逆向 KL 替代正向 KL：L = −(1/T) · E[zT · log_softmax(zS/T)]

学生不再"模仿"教师的所有分布，而是"避开"教师低概率区域（mass-covering）→ 减少幻觉式生成。

GKD（Generalized KD, 2023, Agarwal et al.）

L = (1 − λ) · Lforward(zS, zT) + λ · Lreverse(zS, zT)

λ 控制 forward/reverse 混合，可灵活切换，On-Policy 蒸馏（用 Student 自己生成 + Teacher 评分）。

R1-Distill（DeepSeek 2025.1）

用 R1 生成的 800K 高质量 reasoning trace 做 SFT 蒸馏（不是 KD）

Qwen-1.5B / Llama-8B / Qwen-32B 用 SFT 在 R1 推理数据上 → 在 AIME / MATH 上击败 GPT-4o / o1-mini。

六、Self-Distillation 自蒸馏

让模型从"自己的早期版本"或"自己的多个推理"中学习，Teacher = Student 自己。

  • Born-Again Networks（2018）：Student 学 Teacher（自己旧版本）
  • Self-Distill with CoT：用模型自己的"长 CoT 答案"训练短 CoT 答案
  • Self-Refine / Self-Rewarding：自评 + 自训，LLM-as-Judge 评分
  • Self-Taught Reasoner (STaR)：模型自己解 → 正确解做训练数据
  • Quiet-STaR：在预训练中内化思考
Self-Distillation 的妙处：无需外部大模型作 Teacher，成本低；但质量上限受限于 Student 自己。生产中常配合 RLAIF（用 AI 反馈）做"自己教自己"。

八、R1-Distill 实战与意义

  • 数据：DeepSeek-R1 生成 800K 高质量 reasoning trace（带 R1 思考过程的答案）
  • 学生：Qwen-1.5B / Llama-8B / Qwen-32B / Llama-70B（开源 base）
  • 方法：纯 SFT on reasoning data（不是 logit KD）
  • 效果：Qwen-1.5B 在 AIME 28.9 / MATH-500 71.8%，超过 o1-mini；Qwen-32B 超过 o1-preview
  • 意义：① 证明 reasoning 能力可"蒸馏"到小模型；② 推理时算力可被压缩；③ 小模型 + 强 CoT 数据 > 大模型 + 弱数据
  • 争议：纯 SFT 蒸馏 ≠ 真正学会推理（部分研究显示迁移到难题时退化）

九、训练 / 工程实践

  • 数据生成：Teacher 在大量 prompt 上生成 100K-1M 样本；筛选高质量 + 多样性
  • 温度选择：T=4-20 常见，Classification 任务 T 小，Generation 任务 T 大
  • 蒸馏权重 α：0.5-0.9，混合 CE（保任务能力）+ KL（学暗知识）
  • On-Policy vs Off-Policy：Off-Policy（直接用 Teacher 生成数据）+ On-Policy（Student 生成 + Teacher 评分）
  • 特征蒸馏：当 Student 隐藏维 ≠ Teacher 时，需 projection 层映射
  • 渐进蒸馏：从大 Teacher → 中 → 小，多阶段压缩（DistilBERT 6 层 → TinyBERT 4 层）
  • 与量化结合：先蒸馏到 1/2 尺寸 → 再 INT4 量化 → 保持 90%+ Teacher 能力

十、项目落地 / 业务场景

  • 边缘部署：Llama-70B → Llama-8B，INT4 量化 → 端侧 4GB 内存可跑
  • 成本压缩：自研客服 70B → 7B，QPS 提升 10x，单次推理成本 1/10
  • Reasoning 下放：GPT-o1 类能力 → 自有 7B 模型，私有化部署 + 数据合规
  • 行业模型：通用 70B + 行业 1 万条 SFT → 行业 7B，比从零训练省钱
  • 多语言：英文 Teacher 70B → 中文 Student 7B，知识跨语言迁移

十一、面试 FAQ

Q1：蒸馏的核心思想是什么？

A：让 Student 学 Teacher 的"软标签"——完整概率分布，而不只是 hard label。软标签携带暗知识（哪些近似类被压低、相似度关系）。Hinton 2015 经典公式：CE + α·T²·KL。

Q2：温度 T 起什么作用？

A：T 越大 softmax 越软，概率分布越平 → 暴露更多暗知识（如"猫 0.7 / 狗 0.2"比"猫 1.0"告诉 Student 狗跟猫有一定相似）。T=1 等价标准，T=4-20 常见。乘 T² 补偿软化后梯度量级。

Q3：蒸馏和 SFT 区别？

A：SFT 学 hard label（"答案是 A"），蒸馏学 soft label（"A:0.7, B:0.2"）。SFT 能力上限看数据 / 标注，蒸馏能力上限看 Teacher。SFT 用于任务 / 领域适配，蒸馏用于能力压缩。生产中常组合：SFT 打底 → KD 微调。

Q4：Forward KL vs Reverse KL 区别？

A：Forward KL (zS ‖ zT)：Student 分布尽量"覆盖" Teacher 分布（mass-covering），适合分类。Reverse KL：Student 避开 Teacher 低概率区域（mode-seeking），适合生成（避免幻觉式生成）。MiniLLM 用 Reverse KL，生成质量更好。

Q5：R1-Distill 为什么用 SFT 不用 KD？

A：① R1 的 reasoning trace 是 100K+ token 长 CoT，logit 维度巨大（128K vocab × 100K seq），KD 显存 / 计算代价高；② SFT 直接学"输入→完整推理+答案"序列，简化且有效；③ 800K 高质量 trace 数据本身就是强监督信号；④ 实验显示 SFT-distill 在 reasoning 任务上 ≥ logit KD。

Q6：Self-Distillation 怎么做？

A：Teacher = Student 自己。常见方式：① 不同轮次（早 → 晚）相互学；② 自己多采样投票；③ Self-Rewarding（LLM-as-Judge 打分自己）；④ STaR（自己解题 → 正确解做训练数据）。优点是免费；缺点是质量上限受限于自己。

Q7：特征蒸馏有什么坑？

A：当 Student hidden dim ≠ Teacher 时（如 768 vs 4096），需 projection 层映射（增加参数）。Attention Transfer 需对齐 attention 头数。Feature KD 比 Logit KD 显存大（要存中间 hidden states），不适合超大模型。

Q8：什么时候用 KD 什么时候用 SFT？

A：① Teacher 同源 / 能力远超 Student → KD 划算；② 新任务 / 领域（Teacher 不会）→ SFT；③ 想保留 Teacher 暗知识（推理 / 风格）→ KD；④ 数据稀缺 / 标注贵 → KD（Teacher 生成）；⑤ 端侧 / 高 QPS → KD 后量化。

Q9：蒸馏后还能继续训练吗？

A：可以。常见三阶段：① Pretrain → ② SFT（领域）→ ③ KD（能力压缩）。DistilBERT、Qwen-Distill 都验证可继续 SFT / DPO。KD 后继续 SFT 不会破坏已学能力，前提是 lr 小、数据不冲突。

Q10：R1-Distill 到底算"真推理"还是"模仿"？

A：争议中。支持：① AIME / MATH 显著超过 base；② 推理 token 长度自适应（难题长，简单题短）；③ 错题时能自我纠正。反对：① 复杂规划任务上仍弱于真正 R1；② 难题可能"模仿失败"；③ 学术界（Apple 等）质疑 reasoning 真实性。生产中够用即可。

回答模板与加分项

30 秒电梯版

面试开场可以这样讲：蒸馏让小 Student 学大 Teacher 的软标签分布，捕获暗知识（哪些近似类被压低、相似度关系）。Hinton 2015 经典公式：CE + α·T²·KL。LLM 时代有 MiniLLM（逆向 KL 抗幻觉）、GKD（on-policy 蒸馏）、R1-Distill（DeepSeek 2025 用 800K reasoning trace 蒸馏 1.5B-70B，效果惊人）。生产中蒸馏 + 量化是端侧部署标配。

5 分钟深入版

从动机（部署成本 / 暗知识）→ Hinton KD 公式 → 5 大类方法（Logit / Feature / Attention / Relation / Self / Generation）→ MiniLLM & GKD 的逆向 KL 创新 → R1-Distill 实战 → 与 SFT 区别 → 训练工程实践 → 业务落地。能讲清"为什么 R1-Distill 用 SFT 不用 KD"、"Forward vs Reverse KL 在生成任务上的差异"，立刻显得有真研究。

加分：知道蒸馏局限

蒸馏不是银弹：① Teacher 能力上限 = Student 上限（无法超越）；② Logit KD 显存大（要存 Teacher 输出 / hidden）；③ 特征蒸馏需对齐 hidden dim；④ R1-Distill 复杂推理任务仍弱于真正 R1；⑤ 数据生成成本高（Teacher 跑 N 次）；⑥ 量化后能力会再降，需蒸馏 + 量化联合优化。

加分：能讲一次工程踩坑

比如：用 70B Teacher 蒸馏 7B Student，Logit KD 一开始不收敛（T=1 时 Student 拟合 70B 的 128K vocab softmax 困难）→ 改 T=4 后 loss 下降但生成重复 → 换 MiniLLM 逆向 KL + T=2 → 质量提升；最终 R1-Distill 直接用 SFT on reasoning trace 比 Logit KD 更好。讲清"KD 调参 → 换方法 → 换范式"三步，面试官会立刻认定你有真经验。

面试官可能怎么追问

追问方向示范追问建议回应思路
原理暗知识是什么？答"soft label 的相对关系"：Teacher 给"猫 0.7 / 狗 0.2"比给"猫 1.0"携带更多信息——狗跟猫是相似的，狐狸跟猫也相似。Hard label 把这些都丢掉了。T 越大，暗知识越显。
温度温度 T 怎么选？答"按任务"：分类 T=1-4（softmax 已经够软），生成 T=4-20（需要更多暗知识）。T 太小 → 退化成 hard label；T 太大 → 梯度消失。一般 T=4 是好的起点，调 2-20 网格。
KD vs SFT什么时候用 KD 不用 SFT？答"Teacher 强 + 数据缺"：Teacher 70B 跑 1M prompt 成本 << 1M 人工标注；KD 后 Student 拿到 90% Teacher 能力。SFT 用于新任务 / 领域适配，KD 用于能力压缩。生产组合：SFT 打底 → KD 微调。
Forward/Reverse KL为什么生成用 Reverse KL？答"mode-seeking vs mass-covering"：Forward KL 让 Student 覆盖 Teacher 分布（容易学"什么都像"），Reverse KL 让 Student 避开 Teacher 低概率区域（学"专精"）。生成任务希望 Student 不乱生成 → Reverse KL。
R1-DistillR1-Distill 怎么做的？答"SFT on R1 reasoning trace"：用 DeepSeek-R1 生成 800K 高质量 reasoning trace（带思考过程），Qwen-1.5B/7B/32B/Llama-8B/70B 上 SFT。AIME 28.9%（1.5B）超过 o1-mini 44.6%（小尺寸），32B 接近 R1 原版。
Self-DistillSelf-Distill 怎么避免"自己骗自己"？答"外部验证 + 多样化反馈"：LLM-as-Judge + Ground Truth + 多采样投票。纯自评容易"自欺"，需用工具 / 测试 / 多模型交叉验证。STaR 用正确解做训练数据，Self-Rewarding 用 reward model 评分。
最后提示：蒸馏是 2024-2026 部署 + 推理研究双热门。面试允许说"我只了解原理，未深入训练"，但要能讲清 Hinton KD 公式、温度作用、Forward vs Reverse KL、R1-Distill 创新、与 SFT 区别。诚实 + 思路清晰 > 假装熟练。
