DPO 进阶：从推导到 IPO / KTO / SimPO 家族

DPO 把 RLHF 的"训 RM + PPO"两步折成单阶段监督学习，工程上砍掉 critic、砍掉 RM、训得稳。但 DPO 不是银弹：它对离线数据质量敏感、易"过拟合偏好"、难做 online。本页从推导讲起，串起 IPO / KTO / SimPO / ORPO 等变体的设计动机与适用边界。

一、DPO 损失推导（核心 4 步）

面试金句：DPO 不是"用 SFT 直接拟合偏好"，而是"在 RLHF 最优策略的闭式解下，把奖励用策略自身表达出来"。这一步消除了显式 RM。

三、DPO 的局限性

  • 过拟合偏好：chosen 概率趋向 1，rejected 趋向 0，多样性崩塌
  • 离线数据依赖：数据质量差、覆盖窄 → 学到偏置
  • 难做 online：每次新增偏好都要重训或离线近似
  • Reference 内存贵：同时加载 π_θ 和 π_ref，2 张模型显存
  • 对极端偏好敏感：一条极端数据可能让模型"被带偏"
解决方向正是后面所有变体的动机：去 reference（SimPO / ORPO）、换损失（IPO / KTO）、加约束（DPOP / Iterative DPO）。

五、SimPO 详解

$$L_{\text{SimPO}} = -\log \sigma\!\left(\, \tfrac{\beta}{|y_{w}|} \log \pi_{\theta}(y_{w} \mid x) - \tfrac{\beta}{|y_{l}|} \log \pi_{\theta}(y_{l} \mid x) - \gamma \,\right)$$

两个关键改动：① 用 |y| 归一化 log-prob，抵消"长回答 = 高分"的偏差；② γ 是 margin，让 chosen 和 rejected 之间至少差 γ 才认为对齐。完全不要 reference，显存砍半。

缺点：归一化在长生成任务上有时不稳，需要配合长度 cap。

六、KTO 详解

$$L_{\text{KTO}} = \left(1 - \sigma(z_{\text{ref}})\right) \cdot V_{\text{desirable}} - \sigma(z_{\text{ref}}) \cdot V_{\text{undesirable}}$$

$$z_{\text{ref}} = \beta \cdot \mathrm{KL}\!\left(\pi_{\theta} \,\|\, \pi_{\text{ref}}\right)$$

$$V(\cdot) = \begin{cases} \lambda_{d} \cdot \sigma(\beta \cdot \Delta) & \text{if good} \\ \lambda_{u} \cdot \sigma(-\beta \cdot \Delta) & \text{if bad} \end{cases}$$

灵感来自 Kahneman 前景理论：人对"损失"比"收益"更敏感，所以坏样本权重可以更大。

最大卖点：不需要成对偏好！直接标"这条回答好不好"就行（与 DPO 的 y_w/y_l 对相比）。

七、面试 FAQ

Q1：DPO 为什么不需要显式 RM？

A：推导上，PPO 最优策略有闭式解 π* ∝ π_ref·exp(r/β)，反解出 r 可以用 π_θ/π_ref 的 log 差表达。代入 Bradley-Terry 偏好模型后，Z(x) 项在差分中抵消，训练目标只需要偏好对和 reference。

Q2：DPO 训练时为什么 reference 模型也加载？

A：因为 log-ratio 项 π_θ(y_w)/π_ref(y_w) 需要 reference 的 log-prob 参与计算。一般加载 fp16/bf16 的 reference 不优化器状态，显存约等于 π_θ。SimPO/ORPO 把这层去掉。

Q3：DPO 与 RLHF(PPO) 哪个效果上限高？

A：理论 PPO 更高——它能持续从新数据学习（online），DPO 主要是 offline。但实际中 DPO 因训练稳定、实现简单、显存友好，效果常优于不稳定的 PPO。生产折中：Iterative DPO（多轮 offline）逼近 PPO 上限。

Q4：为什么 SimPO 要做长度归一化？

A：传统 log-prob 随长度累加，模型会学"生成越长越好"的偏差（和 RM 长度偏差同源）。除以 |y| 后，per-token 平均概率成为真正信号。配合 margin γ 进一步拉开 chosen/rejected。

Q5：KTO 什么时候优于 DPO？

A：数据量少、偏好标注稀缺时——KTO 不需成对，可以用单条标注数据。也能利用"好/不好"显式标签之外的隐式信号（如用户采纳 = 喜欢，跳过 = 不喜欢）。代价是对极端样本敏感，需要调 λ_d/λ_u 平衡。

Q6：Iterative DPO 怎么做？

A：每轮用当前 π_θ 对 prompt 采样多个回答，外部 RM 或 GPT-4 打分排序，构造新偏好对，再训 DPO。重复 2-4 轮，效果逼近 PPO 但工程简单。是 Llama-3 / Qwen-2 的官方路径之一。

Q7：β 在 DPO 训练中怎么调？

A：β 大 → 保守（不让 π_θ 离 ref 太远），效果上限低；β 小 → 激进（允许大改动），易过拟合偏好。经验从 0.1 起步，0.3 是常用值，0.5+ 偏保守。也可以做 β schedule（先小后大）。

Q8：DPO 训练多久合适？

A：1-3 epoch 是常见区间。多了模型会"被偏好吸住"，chosen 概率 → 1，rejected → 0，多样性 / 创造力下降。监控 chosen-rejected 的 reward margin，达到阈值后早停。

八、回答模板与加分项

30 秒电梯版

DPO 把 RLHF 的 RM+PPO 折成单阶段监督学习：推导上，PPO 最优策略有闭式解，反解出奖励用 π_θ/π_ref 的 log 差表达，代入 Bradley-Terry 偏好模型后不需要显式 RM。优点是实现简单、训得稳、显存友好；缺点是 offline、过拟合偏好、需要 reference。变体有 IPO / KTO / SimPO / ORPO 解决不同痛点。

5 分钟深入版

从动机（PPO 难训）→ 推导 4 步（PPO 目标 → KL 闭式解 → 反解 implicit reward → 代入 BT 偏好模型）→ 局限（过拟合 / offline / ref 贵）→ 变体家族（IPO 防过拟合、KTO 单条、SimPO 去 ref、ORPO 单阶段、Iterative DPO 逼近 online）→ 选型决策。能讲清"为什么不需要 RM"和"为什么还需要 reference"，立刻拉开差距。

加分：项目案例

讲一次"为什么从 RLHF 切到 DPO"——比如显存不够训 4 模型（policy/ref/RM/value）、训练抖动严重、改 DPO 后一周就出对齐模型；再讲一次"为什么又加 Iterative"——DPO 离线天花板低，加 2 轮迭代后用户满意度 +15%。

加分：知道局限

DPO 不是银弹：① 偏好数据质量差会学坏；② 过拟合偏好让多样性下降（"被偏好吸住"）；③ 难做 online RL；④ reference 加载显存仍贵（2 张模型）。诚实说局限比假装完美得分更高。
