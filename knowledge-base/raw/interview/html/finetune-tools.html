模型微调工具链：Axolotl / Unsloth / LLaMA-Factory / TRL / PEFT

2023 年以来 LLM 微调工具链爆发式发展——从 HuggingFace PEFT/TRL 标准库，到 Unsloth 的内核级加速、Axolotl 的 YAML 配置范式、LLaMA-Factory 的 Web UI、Swift 的国产模型覆盖、bitsandbytes 的 4-bit 量化。生产级微调不再是"手写 Trainer + 写 dataloader"，而是用一站式框架：YAML 写配置 / Web UI 点点 / 一行命令启动分布式。本页把 8 大工具、完整流水线、代码模板、选型决策、面试 FAQ 一次性串清楚。

一、为什么需要专门的微调工具

  • 重复造轮子代价高：从零写 PyTorch 训练循环要处理：混合精度（AMP / BF16）、梯度累积、ZeRO 切分、LoRA 注入、packing、checkpoint 续训——动辄 1000+ 行
  • 生态碎片化：LoRA 实现有十几种（PEFT / LoRA+ / DoRA / AdaLoRA / IA3 / LongLoRA / ReLoRA），量化有 GPTQ/AWQ/bnb 4bit/NF4，需要统一入口
  • 训练稳定性坑多：gradient checkpointing、flash attention、sequence packing、liger kernel、ROPE scaling、NEFTune 噪声——一行配错就 OOM
  • 模型/数据集格式混乱：每个基座（Llama/Qwen/GLM/Baichuan）chat template 不同，工具链统一抽象
  • 分布式需求：DDP / FSDP / DeepSpeed ZeRO-3 / 多机多卡需要配置——框架把这些做成一行配置项
  • 评测 / 部署一站式：训练完直接 vLLM / SGLang / Ollama 部署、lm-eval-harness 跑分、merge LoRA 权重
核心结论：2024 年后做 LLM 微调，99% 场景应直接用现成框架（Axolotl/Unsloth/LLaMA-Factory），不要自己从 Trainer 写。手写 Trainer 只在：① 顶会论文要发新算法；② 定制化 GPU 集群；③ 训练范式特殊（如 RLHF 全链路自研）。

三、完整微调流水线（数据 → 训练 → 评估 → 部署）

四、LoRA 训练代码（PEFT + TRL 标准范式）

# 标准 LoRA SFT 训练：PEFT + TRL + transformers
import torch
from datasets import load_dataset
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig
from peft import LoraConfig, prepare_model_for_kbit_training
from trl import SFTTrainer, SFTConfig

# 1. 4-bit 量化（QLoRA）
bnb = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type="nf4",
                         bnb_4bit_compute_dtype=torch.bfloat16,
                         bnb_4bit_use_double_quant=True)
# 2. 加载 + 冻结 base
model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-7B-Instruct",
    quantization_config=bnb, device_map="auto", torch_dtype=torch.bfloat16)
tok = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-7B-Instruct")
tok.pad_token = tok.eos_token
model = prepare_model_for_kbit_training(model)
# 3. LoRA 配置：r=16 / alpha=32 覆盖全 attention+MLP
lora = LoraConfig(r=16, lora_alpha=32, lora_dropout=0.05, bias="none",
    task_type="CAUSAL_LM",
    target_modules=["q_proj","k_proj","v_proj","o_proj","gate_proj","up_proj","down_proj"])
# 4. 数据
ds = load_dataset("yahma/alpaca-cleaned", split="train")
ds = ds.map(lambda x: {"text": f"### I:\n{x['instruction']}\n### R:\n{x['output']}"})
# 5. 训练
args = SFTConfig(output_dir="./qwen7b-lora", num_train_epochs=3,
    per_device_train_batch_size=4, gradient_accumulation_steps=4,
    gradient_checkpointing=True, learning_rate=2e-4, bf16=True,
    max_seq_length=2048, packing=True)
trainer = SFTTrainer(model=model, args=args, train_dataset=ds,
                     peft_config=lora, processing_class=tok)
trainer.train()
# 6. 合并（可选）
trainer.model.merge_and_unload().save_pretrained("./qwen7b-merged")
关键参数：① r=16 / alpha=32 是 LLaMA-Factory 默认；② target_modules 覆盖全 attention+MLP（7B 约 0.5% 参数量）；③ packing=True 提升 30% 吞吐；④ bf16 + gradient_checkpointing 是显存优化标配。

十、面试 FAQ

Q1：Unsloth 怎么加速的？

A：① 手写 Triton kernel 替换 RoPE / SwiGLU / CrossEntropy；② 算子融合（一次 kernel 多步）；③ QLoRA 训练时加速 base 模型前向（虽然 base 冻结）；④ 静态计算图优化；⑤ 4-bit cache 节省显存。实测 2-5x 加速、显存省 40%。代价：仅单卡、生态兼容性略差。

Q2：LLaMA-Factory 优势？

A：① 国产一站式 + 100+ 模型（Qwen/GLM/Baichuan/InternLM）；② Web UI 可视化（零代码训练）；③ 全算法（SFT/DPO/PPO/ORPO/KTO/SimPO）；④ 集成 DeepSpeed/FlashAttn；⑤ 中文文档完善。适合非算法工程师 / 国产模型场景。

Q3：TRL 和 Axolotl 区别？

A：TRL 是 HF 官方 SFT/DPO/PPO/GRPO Trainer 库（Python API 灵活、源码易改、科研友好）。Axolotl 是上层框架（YAML 配置 + 一键启动、面向 100+ 模型、生态标准化）。生产推荐 Axolotl + TRL（Axolotl 内部就是用 TRL）；科研新算法用 TRL 自写。

Q4：PEFT LoRA 怎么注入？

A：① LoraConfig 配置 r/alpha/dropout/target_modules；② get_peft_model(model, config) 包装原模型；③ prepare_model_for_kbit_training 准备 4-bit；④ 训练时只有 LoRA 矩阵反向传播；⑤ merge_and_unload() 合并权重；⑥ target_modules 一般覆盖所有 attention + MLP（q/k/v/o + gate/up/down）。

Q5：QLoRA 和 LoRA 区别？

A：LoRA：base 模型保持 FP16/BF16 全精度 + 注入低秩矩阵。QLoRA（Dettmers 2023）：base 模型 4-bit NF4 量化 + Double Quant + Paged Optimizer + LoRA。QLoRA 把 65B 模型训练从 780GB 降到 <48GB（单卡）。代价：训练速度比 LoRA 慢 30%，但能训更大的模型。

Q6：训练时显存爆了怎么办？

A：① 开 gradient_checkpointing（省 30% 激活）；② 减小 batch_size + 增大 gradient_accumulation；③ QLoRA 4-bit base；④ ZeRO-3 + CPU offload；⑤ sequence packing 减 padding；⑥ bf16；⑦ 减 max_seq_length；⑧ Liger Kernel / FlashAttn 2；⑨ 换 Unsloth。

Q7：LoRA rank 怎么选？

A：经验值：① 简单任务 / 风格微调 → r=8；② 中等任务（领域问答）→ r=16；③ 复杂任务（指令微调 / 推理）→ r=32-64；④ 多任务（adapter 组合）→ r=64-128。LLaMA-Factory 默认 r=16 / alpha=32。alpha 通常 = 2*r。DoRA / AdaLoRA 可在小 rank 下接近大 rank 效果。

Q8：训练后怎么部署？

A：① merge LoRA → 全量权重；② 量化（GPTQ/AWQ/GGUF）；③ vLLM / SGLang / TGI 高吞吐推理（生产首选）；④ Ollama / LM Studio 本地（开发）；⑤ 评估（lm-eval-harness / OpenCompass）；⑥ 监控（Langfuse / Helicone）。LLaMA-Factory 可一键导出 + 部署。

Q9：DeepSpeed 和 FSDP 选哪个？

A：DeepSpeed（微软）：ZeRO-1/2/3 + 优化器切分 + CPU/NVMe offload，成熟稳定。FSDP（PyTorch 原生）：与 PyTorch 深度集成、API 更现代。生产中两者性能接近，DeepSpeed 文档多、FSDP 趋势好。中小规模（≤32 GPU）任选；超大规模（≥64 GPU）推荐 FSDP + Activation Checkpointing。

Q10：训练数据格式有哪些？

A：① Alpaca：`{instruction, input, output}`；② ShareGPT：多轮对话 `[{role, content}, ...]`；③ OpenAI Chat：messages 数组；④ Pretrain：纯文本；⑤ Preference（DPO）：`{prompt, chosen, rejected}`。LLaMA-Factory / Axolotl 都内置识别。生产中 80% 用 ShareGPT 多轮格式。
