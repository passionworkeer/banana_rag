PPO：让 LLM 对齐最稳的强化学习算法

Proximal Policy Optimization。RLHF 阶段 3 的事实标准。本页讲清 4 件事：策略梯度从哪里来、为什么需要重要性采样、clip objective 在限制什么、GAE 在估计什么。配合 GAE、value network、KL 约束一起说，就能把"为什么 PPO 适合 LLM"讲透。

一、策略梯度定理

目标：$$J(\theta) = \mathbb{E}_{\tau \sim \pi_{\theta}}\!\left[\, R(\tau) \,\right]$$

$$\nabla_{\theta} J(\theta) = \mathbb{E}_{\tau \sim \pi_{\theta}}\!\left[\, \nabla_{\theta} \log \pi_{\theta}(\tau) \cdot R(\tau) \,\right]$$

每步展开：$$\nabla_{\theta} J(\theta) = \mathbb{E}\!\left[\, \sum_{t} \nabla_{\theta} \log \pi_{\theta}(a_{t} \mid s_{t}) \cdot R_{t} \,\right]$$

直观：奖励 R 大的轨迹，其 log-prob 沿梯度方向增大；反之减小。但直接用 R 方差极大，所以引入 baseline 和 advantage。

二、Baseline 与 Advantage

$$A(s, a) = Q(s, a) - V(s)$$

— — —

$$V(s) = \mathbb{E}\!\left[\, \sum_{t' \geq t} r_{t'} \,\Big|\, s_{t} = s \,\right]$$

A 解释：在状态 s 下选 a 比平均好多少

减 baseline 不改期望、但大幅降方差。PPO 中 V 由 value network V_ψ(s) 拟合；优势 = 实际回报 − V 估计。

三、重要性采样

$$\mathbb{E}_{x \sim p}\!\left[\, f(x) \,\right] = \mathbb{E}_{x \sim q}\!\left[\, f(x) \cdot \tfrac{p(x)}{q(x)} \,\right]$$

— — —

PPO 用旧策略采样：

$$J(\theta) = \mathbb{E}_{\tau \sim \pi_{\text{old}}}\!\left[\, r_{t}(\theta) \cdot A_{t} \,\right]$$

$$r_{t}(\theta) = \frac{\pi_{\theta}(a_{t} \mid s_{t})}{\pi_{\text{old}}(a_{t} \mid s_{t})}$$

为什么需要：策略梯度是 on-policy，理论上每次更新都要重采样。重要性采样让旧数据能复用，提升样本效率。但新旧策略不能差太远——这就引出 clip。

四、Clip Objective（PPO 核心）

$$L^{\text{CLIP}}(\theta) = \mathbb{E}_{t}\!\left[\, \min\!\left(\, r_{t}(\theta) \cdot A_{t},\; \text{clip}(r_{t}(\theta),\, 1 - \varepsilon,\, 1 + \varepsilon) \cdot A_{t} \,\right) \,\right]$$

$$\varepsilon = 0.1 \sim 0.2$$

clip 把 rt 限制在 [1−ε, 1+ε]，即新旧策略概率比不能差超过 20%。min 保证 A>0 时不激励 r 过大、A<0 时不激励 r 过小。直白说：步子迈小一点，别一次改太多。

五、PPO 完整损失（4 项）

$$L^{\text{PPO}}(\theta) = \mathbb{E}_{t}\!\left[\, L^{\text{CLIP}}(\theta) - c_{1} \cdot L^{\text{VF}}(\theta) + c_{2} \cdot S[\pi_{\theta}](s_{t}) \,\right]$$

— — —

$L^{\text{CLIP}}$：策略目标（上面）

$$L^{\text{VF}} = \left(V_{\theta}(s_{t}) - R_{t}\right)^{2} \quad \text{（value network MSE）}$$

$S[\pi]$：熵正则，鼓励探索

$c_{1} \approx 1$，$c_{2} \approx 0.01$

3 个项各管一摊：策略项管"动作选得好不好"、value 项管"baseline 估得准不准"、熵项管"别过早收敛到单一动作"。LLM 上熵项有时省略。

六、GAE（Generalized Advantage Estimation）

$$A^{\text{GAE}}_{t} = \sum_{l=0}^{\infty} (\gamma \lambda)^{l} \cdot \delta_{t+l}$$

$$\delta_{t} = r_{t} + \gamma \cdot V(s_{t+1}) - V(s_{t})$$

$\gamma \in [0, 1]$：discount

$\lambda \in [0, 1]$：GAE 平滑系数

λ=0 → 1-step TD（低方差、高偏差）；λ=1 → Monte Carlo（高方差、低偏差）；中间值是 trade-off。LLM 训练中 λ=0.95、γ=1 是常见配置。

七、PPO 在 LLM 上的特点

  • On-Policy：每轮用最新策略采样，off-policy 数据不能用
  • 小步更新：clip 限制每次更新幅度，配合多次 epoch 旧数据
  • 需要 V 网络：占一份显存，与策略各 14GB（7B）
  • 需要 Reference：KL 惩罚的参考
  • 稀疏奖励：整句生成完才有 rT，中间 token 无奖励
  • 长序列：T=2048 时一条 trajectory 占大量显存
这些特点导致 PPO 在 LLM 上显存极贵、训练极慢。GRPO、REINFORCE++、RLOO 等"免 critic"方案爆火，本质都是"砍掉 value network 砍一半显存"。

八、面试 FAQ

Q1：PPO 为什么比 REINFORCE 稳？

A：REINFORCE 用整条轨迹回报 Rt，方差巨大。PPO 引入 ① 优势函数 A=Q−V 减 baseline 降方差；② 重要性采样复用旧数据；③ clip 限制策略步长防崩。三件套一起把方差和稳定性都拉上来。

Q2：为什么需要价值网络 V？

A：V(s) 作为 baseline，让优势函数 A=r−V 描述"相对好坏"而非绝对回报，大幅降方差。V_ψ 单独训练，用 MSE 拟合实际回报。

Q3：clip 系数 ε 怎么选？

A：经验 0.1-0.2。ε 大 → 允许大步更新（激进、可能崩）；ε 小 → 步子小（保守、训练慢）。0.2 是 OpenAI 默认。也有 adaptive KL 替代 clip（早期 PPO 论文）。

Q4：为什么 PPO 是 on-policy？

A：重要性采样理论上支持 off-policy，但新旧策略差太远时 ratio 噪声爆炸。PPO 通过 clip 限制这个差距在 [1−ε, 1+ε]，所以实际只能在"接近 on-policy"时稳定运行。每个 PPO epoch 之前会重采样。

Q5：KL 惩罚和 clip 是冗余的吗？

A：不一样。clip 限制单步更新幅度（局部）；KL 惩罚限制与 reference 的总偏离（全局）。LLM RLHF 中 KL 必加（防 SFT 能力遗忘），clip 必加（防训练崩）。两者互补。

Q6：PPO 在 LLM 上最大痛点？

A：4 个模型同时跑（policy / ref / RM / value），显存 4×14GB=56GB 起步（7B）；reward 稀疏只有末 token 有分；长序列下 trajectory 占大量显存；策略和 RM 互相博弈易震荡。

Q7：GRPO 和 PPO 核心区别？

A：GRPO 砍掉 value network，对同 prompt 采样 N 个回答，用组内归一化分数当 advantage。显存从 4 模型降到 2 模型，且 advantage 估计更稳定（组内对比天然去偏差）。

Q8：LLM 上 PPO 的 GAE 怎么用？

A：每个生成 token 位置算 δt = rt + γV(st+1) − V(st)，但中间 token 无 reward（rt=0），只有末 token 有 rT。GAE 从 t=T 反向传播回算各步 advantage。γ=1、λ=0.95 常见。

九、回答模板与加分项

30 秒电梯版

PPO 是 on-policy 的策略梯度算法，三件套：① 重要性采样复用旧数据；② clip objective 限制单步更新幅度在 [1−ε, 1+ε]；③ GAE 用 value network 估计 advantage 降方差。LLM RLHF 中 PPO 是标准选择，但 4 模型显存贵、训练不稳，所以工业界演化出 GRPO/REINFORCE++/DPO 等替代。

5 分钟深入版

从策略梯度定理出发 → 引出 baseline 和 advantage → 解释重要性采样（为什么能复用旧数据）→ clip 在限制什么（步长）→ GAE 在估计什么（多步 advantage 平滑）→ LLM 上的具体改动（4 模型、稀疏 reward、KL 约束）→ 与 GRPO 对比（为什么免 critic 反而更好）。能讲清"为什么 LLM 上 PPO 这么贵"立刻显得有真经验。

加分：踩坑案例

讲一次真实事故：① clip 系数设 0.5，PPO 步子太大，模型崩坏；② value network 没 warmup，前 1000 步 advantage 估计全错；③ KL 系数设 0.001，模型完全偏离 SFT，生成乱码；④ reward 模型有 bug，PPO 学到了"刷 reward 分数"的能力。讲排查过程（看 ratio 分布、KL 曲线、reward 趋势）立刻显得有真经验。

加分：知道 PPO 局限

PPO 不是银弹：① 4 模型显存贵；② 训练不稳定（reward hacking）；③ on-policy 样本效率低；④ GAE 实现复杂；要诚实说"PPO 在工业界正被 GRPO/RLOO 部分替代，但仍是 RLHF 的 baseline 算法"。
