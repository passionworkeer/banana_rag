SFT：让模型学会“按指定任务回答”

SFT 的核心是用高质量输入输出样本，把基座模型调成更符合任务格式和领域习惯的模型。面试重点不是“训了一下模型”，而是数据怎么构造、loss 怎么算、mask 怎么做、怎么避免只学模板。

Loss Mask 怎么讲

内容是否算 loss原因
system prompt通常不算它是控制指令，不是模型目标输出
user input通常不算用户输入不是模型要生成的内容
assistant answer算模型要学习的目标回答
tool response通常不算外部工具结果不应由模型伪造

知识点拆解

1. SFT 学什么

学任务格式、领域表达、回答风格和基本能力调用方式，不适合直接解决复杂偏好排序。

2. 数据质量

高质量样本要覆盖多类型、多难度、多边界条件，且答案标准一致。低质量重复样本会让模型模板化。

3. LoRA 关系

SFT 是训练阶段，LoRA 是参数高效训练方法。可以用 LoRA 做 SFT，也可以全量微调做 SFT。

4. 什么时候不够

当问题不是“会不会答”，而是“哪个答案更符合偏好”时，要考虑 DPO 或 RLHF。

面试回答模板

“SFT 是用高质量监督数据让模型学习目标任务。训练时要把对话转成 token 序列，用 causal LM loss 预测下一个 token，同时对 system、user、padding 和工具返回做 mask，只训练 assistant 该生成的部分。”

常见追问与回答

为什么要 shift right？

因为自回归模型的训练目标就是“用前文预测后文”。如果不 shift，模型会看到答案再预测答案，训练和推理不一致，目标也会失真。

tool response 需要 loss mask 吗？

一般需要。工具返回是外部系统的结果，不应该让模型去学习“伪造”工具输出。常见做法是只训练 assistant 的自然语言答案或行动决策部分。

数据怎么保证多样性？

要覆盖不同任务类型、格式、长度、难度和边界条件，不能只堆模板化的标准答案。越接近真实业务分布的数据越有效。

为什么 loss 降了但 F1 不涨？

可能是训练目标和最终任务指标不一致，也可能是类别不均衡、阈值不对、数据有噪声或过拟合模板。要同时看分布、阈值和错误类型。
