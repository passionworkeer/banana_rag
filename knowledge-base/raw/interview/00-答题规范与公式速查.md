# 00 答题规范与公式速查

这份文件不是单独题库，而是你后面看所有题时都能复用的“答题骨架 + 公式卡片 + HTML 展示模板”。

## 1. 通用答题结构

建议每题都按下面顺序讲：

1. **一句话结论**：先把答案说出来。
2. **核心原理**：解释它为什么成立。
3. **知识点展开**：补公式、定义、边界和对比。
4. **工程落地**：在项目里怎么用。
5. **常见追问**：提前补面试官会继续问的点。

示例：

```text
结论：这题核心是 XXX。
原理：它本质上解决的是 XXX。
知识点：这里牵涉到 A、B、C 三块。
落地：我在项目里会这样设计。
追问：如果面试官继续问，我会补 XXX。
```

## 3. 通用公式卡

### Attention

```text
Q = XWq
K = XWk
V = XWv
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k))V
```

### Cross-Entropy

```text
L = - \sum_i y_i \log p_i
```

### Softmax

```text
softmax(z_i) = e^{z_i} / \sum_j e^{z_j}
```

### 余弦相似度

```text
cos(x, y) = (x \cdot y) / (||x|| ||y||)
```

### 欧氏距离

```text
d(x, y) = sqrt(\sum_i (x_i - y_i)^2)
```

### F1

```text
F1 = 2 * Precision * Recall / (Precision + Recall)
```

### KL 散度

```text
KL(P || Q) = \sum_i P(i) \log(P(i) / Q(i))
```

### LoRA

```text
W' = W + BA
```

### DPO 直观形式

```text
loss = -log sigmoid(beta * [(log pi(chosen)-log pi(rejected))
                            - (log ref(chosen)-log ref(rejected))])
```

## 4. 常见表达模板

### 讲技术题

> 先给结论，再解释原理，再补一个工程落地例子，最后说一下风险点。

### 讲项目题

> 问题是什么、我怎么拆、我具体做了什么、怎么验证结果。

### 讲优化题

> 先定位瓶颈，再分成数据、模型、系统、评估四层看。

### 讲评估题

> 先拆检索、生成、端到端，再补离线和在线指标。
